Abstract

UAV-based pavement inspection can reduce cost and safety risk, but active-road deployment remains challenging when vehicles, pedestrians, and temporary occlusions affect road-surface visibility. We present a Unity-based digital twin framework for traffic-aware UAV pavement monitoring in open-traffic conditions. The environment integrates procedurally generated pavement defects, dynamic traffic agents, UAV inspection behavior, and a deployable perception module.

The perception module uses a shared-backbone multi-task YOLO architecture: the image is encoded once, a detection head localizes Road-defect-general, Person, and Car, and an ROIAlign-based subtype head refines road-defect regions into Crocodile Crack, Single Crack, or Pothole. This avoids the repeated RGB crop re-encoding used by crop-classifier pipelines while preserving final five-class outputs.

Method Overview

The framework combines a simulation layer, inspection-policy layer, and perception layer. The simulator provides road scenes and dynamic occluders; the UAV captures inspection frames; the perception model returns traffic-agent and road-defect detections; and recovery policies decide how the UAV reacts to temporary occlusions.

Shared-Backbone Multi-Task YOLO

The model is deliberately not trained as a plain five-class YOLO detector. The detection head predicts a coarse road-defect class plus road users, while the subtype head classifies only road-defect regions using shared feature maps.

Experimental Results

The final model was trained on the balanced real-image dataset and then fine-tuned on the synthetic simulator dataset. Evaluation was performed on the held-out synthetic test split used in the paper.

Baseline inspection

The UAV follows the planned coverage route and does not explicitly recover occluded road segments.

Hover-and-recheck

The UAV waits over the target segment, allowing temporary traffic occlusions to clear before continuing inspection.

Micro-repositioning

The UAV performs a small lateral displacement to recover visibility while remaining close to the target road segment.

Skip-and-revisit

The UAV continues to the next segment and schedules the occluded segment for a later revisit.

Deployment Notes

The current deployment uses a local Python FastAPI server. This is the most reliable deployment path for the custom ROIAlign branch and shared-backbone checkpoint. 

Unity → POST /predict → FastAPI → best.pt → JSON detections

Current path

  • PyTorch checkpoint: models/model_finetuned.pt
  • Server: unity/Assets/Scripts/AI/api_model_pt.py
  • Endpoint: http://127.0.0.1:5000/predict
  • Runtime path: Unity captures a frame, sends it to FastAPI, and receives JSON detections.
